# Telegram Мьют-Бот 🤖

Бот для модерации группового чата в Telegram с системой голосования за ограничения пользователей.

## Возможности

### Команды для всех участников чата

- **`/tishe`** - Голосование за запрет отправки медиа (фото, видео, голосовых)
  - Требуется **3 голоса** для активации
  - Ограничение действует **24 часа**
  - Пользователь может писать текст, но не может отправлять медиа

- **`/zaebal`** - Голосование за полный мьют пользователя
  - Требуется **5 голосов** для активации
  - Ограничение действует **24 часа**
  - Пользователь полностью замьючен (не может писать ничего)

- **`/status`** - Показать список активных ограничений
  - Отображает всех замьюченных пользователей
  - Показывает оставшееся время ограничения

- **`/target_list`** - Показать список пользователей, на которых можно голосовать

### Команды для администраторов

- **`/target_add`** - Добавить пользователя в список для голосования
  - Используйте как ответ на сообщение пользователя
  - После добавления на этого пользователя можно использовать /tishe и /zaebal

- **`/target_remove`** - Убрать пользователя из списка
  - Используйте как ответ на сообщение пользователя
  - После удаления на этого пользователя нельзя голосовать

### Система целевых пользователей

Бот работает с системой "белого списка" - голосовать можно **только** на тех пользователей, которых администратор добавил в список целевых. Это защищает остальных участников чата от случайного мьюта.

**Важно:** Все участники чата могут голосовать, но мьютить можно только тех, кто в списке целевых.

## Установка и настройка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен (он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd antipopog

# Установите Python 3.8+ если ещё не установлен

# Установите зависимости
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен вашего бота:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Добавление бота в группу

1. Добавьте бота в ваш групповой чат
2. Откройте настройки группы → Администраторы → Добавить администратора
3. Выберите вашего бота
4. Включите следующие права:
   - ✅ Удаление сообщений
   - ✅ Блокировка пользователей
   - ✅ Приглашение пользователей по ссылке

**Важно:** Без прав администратора бот не сможет ограничивать пользователей!

### 5. Запуск бота

```bash
python bot.py
```

Бот запустится и будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Использование

### Первичная настройка (для администраторов)

1. Определите, кого из участников чата вы хотите добавить в список для голосования
2. Ответьте на сообщение этого пользователя командой `/target_add`
3. Бот подтвердит добавление
4. Повторите для других участников по необходимости
5. Используйте `/target_list` для просмотра списка

### Голосование за запрет медиа

1. Кто-то из **целевых пользователей** отправляет слишком много медиа
2. Ответьте на любое его сообщение командой `/tishe`
3. Другие участники тоже отвечают на его сообщения с `/tishe`
4. После 3-х голосов пользователь автоматически получает запрет на отправку медиа

**Примечание:** Если пользователь не в списке целевых, бот сообщит что на него нельзя голосовать.

### Голосование за полный мьют

1. Кто-то из **целевых пользователей** спамит или ведет себя неадекватно
2. Ответьте на любое его сообщение командой `/zaebal`
3. Другие участники тоже отвечают на его сообщения с `/zaebal`
4. После 5-ти голосов пользователь автоматически замьючен

### Проверка статуса

- `/status` - Увидеть всех замьюченных пользователей и время до снятия ограничений
- `/target_list` - Увидеть список пользователей, на которых можно голосовать

## Примеры

### Пример 1: Добавление в список целевых

```
Вася: Привет всем!
Админ: /target_add (ответ на сообщение Васи)

Бот: ✅ Пользователь Вася добавлен в список для голосования.
     Теперь на него можно использовать команды /tishe и /zaebal
```

### Пример 2: Голосование за запрет медиа

```
Вася: [отправляет 100500-е видео с котиками]
Петя: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 1/3 для запрета медиа

Маша: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 2/3 для запрета медиа

Коля: /tishe (ответ на сообщение Васи)
Бот: 🔇 Вася не может отправлять медиа в течение 24 часов!
     Голосов набрано: 3/3
```

### Пример 3: Попытка голосовать за пользователя не из списка

```
Незнакомец: Спам спам спам!
Петя: /zaebal (ответ на сообщение Незнакомца)

Бот: ❌ На пользователя Незнакомец нельзя голосовать.
     Администратор должен добавить его в список командой /target_add
```

## Запуск в фоне (опционально)

### Использование screen

```bash
screen -S telegram-bot
python bot.py
# Нажмите Ctrl+A, затем D для выхода из screen
# Вернуться: screen -r telegram-bot
```

### Использование systemd (Linux)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Mute Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/antipopog
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/usr/bin/python3 /path/to/antipopog/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot
```

## Настройка параметров

В файле `bot.py` можно изменить параметры:

```python
TISHE_VOTES_REQUIRED = 3  # Количество голосов для запрета медиа
ZAEBAL_VOTES_REQUIRED = 5  # Количество голосов для полного мьюта
RESTRICTION_DURATION = timedelta(hours=24)  # Длительность ограничения
```

- **Хранение данных:** В памяти (при перезапуске бота данные о голосах сбрасываются, но активные ограничения в Telegram остаются)

## Безопасность

- **Система целевых пользователей:** Голосовать можно только на тех, кого админ добавил в список
- **Защита от самоголосования:** Нельзя голосовать за самого себя
- **Один голос:** Один пользователь может проголосовать только один раз за конкретное сообщение
- **Привязка к сообщению:** Голоса привязаны к конкретному сообщению
- **Автоматическое снятие:** Ограничения автоматически снимаются через 24 часа
- **Только для админов:** Команды управления целевыми пользователями доступны только администраторам чата

## Решение проблем

### Бот не ограничивает пользователей

Проверьте:
1. Бот добавлен в группу как администратор
2. У бота есть права на блокировку пользователей
3. В логах нет ошибок

### Команды не работают

Убедитесь:
1. Команды отправляются как **ответ** на сообщение
2. Бот запущен и работает
3. Токен в `.env` файле правильный

### Не могу голосовать за пользователя

Проверьте:
1. Пользователь добавлен в список целевых командой `/target_add`
2. Используйте `/target_list` чтобы увидеть список
3. Только администратор может добавлять пользователей в список

### Команды администратора не работают

Убедитесь:
1. Вы являетесь администратором группы
2. У вас есть права администратора в настройках группы
3. Бот может проверить ваш статус (нужны базовые права администратора)

### Бот не запускается

Проверьте:
1. Установлены все зависимости: `pip install -r requirements.txt`
2. Создан файл `.env` с токеном
3. Токен валидный и не истёк
