# Telegram Мьют-Бот 🤖

Бот для модерации группового чата в Telegram с системой голосования за ограничения пользователей.

## Возможности

### Команды (в ответ на сообщение)

- **`/tishe`** - Голосование за запрет отправки медиа (фото, видео, голосовых)
  - Требуется **5 голосов** для активации
  - Ограничение действует **1 час**
  - Пользователь может писать текст, но не может отправлять медиа

- **`/zaebal`** - Голосование за полный мьют пользователя
  - Требуется **5 голосов** для активации
  - Ограничение действует **1 час**
  - Пользователь полностью замьючен (не может писать ничего)

- **`/status`** - Показать список активных ограничений
  - Отображает всех замьюченных пользователей
  - Показывает оставшееся время ограничения

### Правила голосования

- ✅ Голосовать можно за **всех**, кроме администраторов
- ⏱️ Голоса **сгорают** через 1 час, если не набран порог
- 🕐 **Кулдаун** между голосами одного пользователя против другого - 1 час
- ❌ Нельзя голосовать за самого себя
- ❌ Нельзя голосовать за администраторов чата

## Установка и настройка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен (он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd antipopog

# Установите Python 3.8+ если ещё не установлен

# Установите зависимости
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и настройте параметры:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather

# Опционально: URL гифки для отправки при успешном мьюте
MUTE_GIF_URL=https://media.giphy.com/media/your-gif-id/giphy.gif

# Или можно указать разные гифки для разных типов мьюта:
# TISHE_GIF_URL=https://url-to-tishe-gif.gif
# ZAEBAL_GIF_URL=https://url-to-zaebal-gif.gif
```

**Примечание:** Гифка отправляется в чат при успешном применении ограничения. Это опционально - если не указать URL, бот будет работать без гифок.

### 4. Добавление бота в группу

1. Добавьте бота в ваш групповой чат
2. Откройте настройки группы → Администраторы → Добавить администратора
3. Выберите вашего бота
4. Включите следующие права:
   - ✅ Удаление сообщений
   - ✅ Блокировка пользователей
   - ✅ Приглашение пользователей по ссылке

**Важно:** Без прав администратора бот не сможет ограничивать пользователей!

### 5. Запуск бота

```bash
python bot.py
```

Бот запустится и будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Использование

### Голосование за запрет медиа

1. Кто-то отправляет слишком много медиа (но не админ)
2. Ответьте на любое его сообщение командой `/tishe`
3. Другие участники тоже отвечают на его сообщения с `/tishe`
4. После 5-ти голосов пользователь автоматически получает запрет на отправку медиа на 1 час
5. Голоса сгорают через 1 час, если порог не достигнут

### Голосование за полный мьют

1. Кто-то спамит или ведет себя неадекватно (но не админ)
2. Ответьте на любое его сообщение командой `/zaebal`
3. Другие участники тоже отвечают на его сообщения с `/zaebal`
4. После 5-ти голосов пользователь автоматически замьючен на 1 час
5. Голоса сгорают через 1 час, если порог не достигнут

### Ограничения

- Нельзя голосовать за одного и того же пользователя чаще раза в час
- После голосования нужно подождать час, прежде чем снова голосовать за этого пользователя
- Администраторы защищены от мьюта

### Проверка статуса

Используйте `/status` чтобы увидеть всех замьюченных пользователей и время до снятия ограничений.

## Примеры

### Пример 1: Голосование за запрет медиа

```
Вася: [отправляет 100500-е видео с котиками]
Петя: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 1/5 для запрета медиа

Маша: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 2/5 для запрета медиа

Коля: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 3/5 для запрета медиа

Саша: /tishe (ответ на сообщение Васи)
Бот: 🔕 Голос учтён! 4/5 для запрета медиа

Лена: /tishe (ответ на сообщение Васи)
Бот: 🔇 Вася не может отправлять медиа в течение 1 часа!
     Голосов набрано: 5/5
```

### Пример 2: Кулдаун голосования

```
Петя: /zaebal (ответ на сообщение Васи)
Бот: 🔇 Голос учтён! 1/5 для полного мьюта

[Через 5 минут]
Петя: /zaebal (ответ на другое сообщение Васи)
Бот: ⏳ Вы уже голосовали за Вася. Подождите ещё 55 мин.
```

### Пример 3: Попытка голосовать за администратора

```
Админ: Всем привет!
Петя: /zaebal (ответ на сообщение Админа)

Бот: ❌ Нельзя голосовать за администраторов!
```

## Запуск в фоне (опционально)

### Использование screen

```bash
screen -S telegram-bot
python bot.py
# Нажмите Ctrl+A, затем D для выхода из screen
# Вернуться: screen -r telegram-bot
```

### Использование systemd (Linux)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Mute Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/antipopog
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/usr/bin/python3 /path/to/antipopog/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot
```

## Настройка параметров

В файле `bot.py` можно изменить параметры:

```python
TISHE_VOTES_REQUIRED = 5  # Количество голосов для запрета медиа
ZAEBAL_VOTES_REQUIRED = 5  # Количество голосов для полного мьюта
RESTRICTION_DURATION = timedelta(hours=1)  # Длительность ограничения
VOTE_EXPIRATION = timedelta(hours=1)  # Время жизни голоса
VOTE_COOLDOWN = timedelta(hours=1)  # Кулдаун между голосами
```

## Технические детали

- **Язык:** Python 3.8+

- **Хранение данных:** В памяти (при перезапуске бота данные о голосах сбрасываются, но активные ограничения в Telegram остаются)

## Безопасность

- **Защита администраторов:** Нельзя голосовать за администраторов чата
- **Защита от самоголосования:** Нельзя голосовать за самого себя
- **Кулдаун голосования:** Один пользователь может голосовать против другого раз в час
- **Сгорание голосов:** Голоса автоматически сгорают через 1 час
- **Один голос за сообщение:** Один пользователь может проголосовать только один раз за конкретное сообщение
- **Автоматическое снятие:** Ограничения автоматически снимаются через 1 час

## Решение проблем

### Бот не ограничивает пользователей

Проверьте:
1. Бот добавлен в группу как администратор
2. У бота есть права на блокировку пользователей
3. В логах нет ошибок

### Команды не работают

Убедитесь:
1. Команды отправляются как **ответ** на сообщение
2. Бот запущен и работает
3. Токен в `.env` файле правильный

### Не могу голосовать за пользователя

Проверьте:
1. Пользователь не является администратором (админы защищены от мьюта)
2. Вы не голосовали за этого пользователя в последний час (кулдаун)
3. Вы не пытаетесь голосовать за самого себя

### Бот не запускается

Проверьте:
1. Установлены все зависимости: `pip install -r requirements.txt`
2. Создан файл `.env` с токеном
3. Токен валидный и не истёк
