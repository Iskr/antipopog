# Telegram Мьют-Бот 🤖

Бот для модерации группового чата в Telegram с системой голосования за ограничения пользователей.

## Возможности

### Команды (в ответ на сообщение)

- **`/tishe`** - Голосование за запрет отправки медиа (фото, видео, голосовых)
  - Требуется **5 голосов** для активации
  - Базовое ограничение: **3 часа**
  - **Прогрессивные баны:** каждый следующий бан добавляет +5 минут
  - Пользователь может писать текст, но не может отправлять медиа

- **`/zaebal`** - Голосование за полный мьют пользователя
  - Требуется **5 голосов** для активации
  - Базовое ограничение: **3 часа**
  - **Прогрессивные баны:** каждый следующий бан добавляет +5 минут
  - Пользователь полностью замьючен (не может писать ничего)

- **`/status`** - Показать активные ограничения, голосования и статистику
  - Отображает всех замьюченных пользователей и время до снятия ограничений
  - Показывает текущие активные голосования и количество набранных голосов
  - **Статистика нарушений:** показывает количество банов каждого пользователя

### Прогрессивные баны

Система запоминает количество нарушений каждого пользователя:

| Бан | Длительность | Доп. время |
|-----|-------------|------------|
| 1-й | 3 часа      | — |
| 2-й | 3 часа 5 мин | +5 мин |
| 3-й | 3 часа 10 мин | +10 мин |
| 4-й | 3 часа 15 мин | +15 мин |
| ... | ... | +5 мин за каждый |

**Данные сохраняются** в файл `ban_data.json` и не теряются при перезапуске бота.

### Правила голосования

- ✅ Голосовать можно за **всех**, кроме администраторов
- 📊 Голоса **считаются по пользователю**, а не по сообщению (можно голосовать на разные сообщения одного человека)
- ⏱️ Голоса **живут 24 часа** (повторный голос продлевает срок)
- ❌ Нельзя голосовать за самого себя
- ❌ Нельзя голосовать за администраторов чата
- 🌍 Время работает в **UTC**, поэтому ограничения будут корректными независимо от часового пояса сервера

## Установка и настройка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен (он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd antipopog

# Установите Python 3.8+ если ещё не установлен

# Установите зависимости
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и настройте параметры:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather

# Опционально: URL гифки для отправки при успешном мьюте
MUTE_GIF_URL=https://media.giphy.com/media/your-gif-id/giphy.gif

# Или можно указать разные гифки для разных типов мьюта:
# TISHE_GIF_URL=https://url-to-tishe-gif.gif
# ZAEBAL_GIF_URL=https://url-to-zaebal-gif.gif
```

**Примечание:** Гифка отправляется в чат при успешном применении ограничения. Это опционально - если не указать URL, бот будет работать без гифок.

### 4. Добавление бота в группу

1. Добавьте бота в ваш групповой чат
2. Откройте настройки группы → Администраторы → Добавить администратора
3. Выберите вашего бота
4. Включите следующие права:
   - ✅ Удаление сообщений
   - ✅ Блокировка пользователей
   - ✅ Приглашение пользователей по ссылке

**Важно:** Без прав администратора бот не сможет ограничивать пользователей!

### 5. Запуск бота

```bash
python bot.py
```

Бот запустится и будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Использование

### Голосование за запрет медиа

1. Кто-то отправляет слишком много медиа (но не админ)
2. Ответьте на **любое** его сообщение командой `/tishe`
3. Другие участники тоже отвечают на **любые** его сообщения с `/tishe` (можно на разные)
4. После 5-ти голосов пользователь автоматически получает запрет на отправку медиа на 3 часа
5. Голоса сгорают через 24 часа, если порог не достигнут

### Голосование за полный мьют

1. Кто-то спамит или ведет себя неадекватно (но не админ)
2. Ответьте на **любое** его сообщение командой `/zaebal`
3. Другие участники тоже отвечают на **любые** его сообщения с `/zaebal` (можно на разные)
4. После 5-ти голосов пользователь автоматически замьючен на 3 часа
5. Голоса сгорают через 24 часа, если порог не достигнут

### Ограничения

- Один пользователь = один голос за цель (повторный голос продлевает срок на 24ч)
- Администраторы защищены от мьюта

### Проверка статуса

Используйте `/status` чтобы увидеть:
- Всех замьюченных пользователей и время до снятия ограничений
- Текущие активные голосования (например: "За Васю: /tishe 3/5 голосов")

## Запуск в фоне (опционально)

### Использование screen

```bash
screen -S telegram-bot
python bot.py
# Нажмите Ctrl+A, затем D для выхода из screen
# Вернуться: screen -r telegram-bot
```

### Использование systemd (Linux)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Mute Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/antipopog
Environment="PATH=/path/to/antipopog/venv/bin"
ExecStart=/path/to/antipopog/venv/bin/python3 bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot

# Просмотр логов
sudo journalctl -u telegram-bot -f
```

## Настройка параметров

В файле `bot.py` можно изменить параметры:

```python
TISHE_VOTES_REQUIRED = 5  # Количество голосов для запрета медиа
ZAEBAL_VOTES_REQUIRED = 5  # Количество голосов для полного мьюта
RESTRICTION_DURATION = timedelta(hours=3)  # Базовая длительность ограничения
VOTE_EXPIRATION = timedelta(hours=24)  # Время жизни голоса (сутки)
BAN_INCREMENT = timedelta(minutes=5)  # Добавка времени за каждый предыдущий бан
```

## Технические детали

- **Язык:** Python 3.8+
- **Библиотека:** python-telegram-bot 20.7
- **Хранение данных:**
  - Все данные (голоса, история банов) сохраняются в `ban_data.json`
  - Данные сохраняются после каждого голоса и не теряются при перезапуске
  - Активные ограничения в Telegram остаются даже после перезапуска бота
- **Часовой пояс:** Использует UTC для корректной работы независимо от часового пояса сервера

### Архитектура системы голосования

- Голоса считаются **по пользователю**, а не по сообщению
- Можно голосовать на разные сообщения одного пользователя - все голоса суммируются
- Повторный голос **продлевает** срок жизни голоса на 24 часа
- Просроченные голоса автоматически удаляются при проверке

## Безопасность

- **Защита администраторов:** Нельзя голосовать за администраторов чата
- **Защита от самоголосования:** Нельзя голосовать за самого себя
- **Сгорание голосов:** Голоса автоматически сгорают через 24 часа
- **Автоматическое снятие:** Ограничения автоматически снимаются через 3 часа
- **Один голос:** Один пользователь = один голос за цель (повторный продлевает срок)

## Решение проблем

### Бот не ограничивает пользователей

Проверьте:
1. Бот добавлен в группу как администратор
2. У бота есть права на блокировку пользователей
3. В логах нет ошибок

### Команды не работают

Убедитесь:
1. Команды отправляются как **ответ** на сообщение
2. Бот запущен и работает
3. Токен в `.env` файле правильный

### Не могу голосовать за пользователя

Проверьте:
1. Пользователь не является администратором (админы защищены от мьюта)
2. Вы не пытаетесь голосовать за самого себя

### Неправильное время ограничений

Бот использует UTC время. Если ограничение показывает неправильное время, убедитесь что:
1. Бот использует последнюю версию кода (с `datetime.now(timezone.utc)`)
2. Перезапустите бота после обновления

### Бот не запускается

Проверьте:
1. Установлены все зависимости: `pip install -r requirements.txt`
2. Создан файл `.env` с токеном
3. Токен валидный и не истёк
