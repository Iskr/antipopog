# Telegram Мьют-Бот 🤖

Бот для модерации группового чата в Telegram с системой голосования за ограничения пользователей.

## Возможности

- **`/tishe`** - Голосование за запрет отправки медиа (фото, видео, голосовых)
  - Требуется **3 голоса** для активации
  - Ограничение действует **24 часа**
  - Пользователь может писать текст, но не может отправлять медиа

- **`/zaebal`** - Голосование за полный мьют пользователя
  - Требуется **5 голосов** для активации
  - Ограничение действует **24 часа**
  - Пользователь полностью замьючен (не может писать ничего)

- **`/status`** - Показать список активных ограничений
  - Отображает всех замьюченных пользователей
  - Показывает оставшееся время ограничения

## Установка и настройка

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Скопируйте токен (он выглядит как `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd antipopog

# Установите Python 3.8+ если ещё не установлен

# Установите зависимости
pip install -r requirements.txt
```

### 3. Настройка конфигурации

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен вашего бота:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

### 4. Добавление бота в группу

1. Добавьте бота в ваш групповой чат
2. Откройте настройки группы → Администраторы → Добавить администратора
3. Выберите вашего бота
4. Включите следующие права:
   - ✅ Удаление сообщений
   - ✅ Блокировка пользователей
   - ✅ Приглашение пользователей по ссылке

**Важно:** Без прав администратора бот не сможет ограничивать пользователей!

### 5. Запуск бота

```bash
python bot.py
```

Бот запустится и будет работать до тех пор, пока вы не остановите его (Ctrl+C).

## Использование

### Голосование за запрет медиа

1. Кто-то в чате отправляет слишком много медиа
2. Ответьте на любое его сообщение командой `/tishe`
3. Другие участники тоже отвечают на его сообщения с `/tishe`
4. После 3-х голосов пользователь автоматически получает запрет на отправку медиа

### Голосование за полный мьют

1. Кто-то в чате спамит или ведет себя неадекватно
2. Ответьте на любое его сообщение командой `/zaebal`
3. Другие участники тоже отвечают на его сообщения с `/zaebal`
4. После 5-ти голосов пользователь автоматически замьючен

### Проверка статуса

Отправьте `/status` в чат, чтобы увидеть всех замьюченных пользователей и время до снятия ограничений.

## Примеры

```
Вася: [отправляет 100500-е видео с котиками]
Петя: /tishe (ответ на сообщение Васи)
Маша: /tishe (ответ на сообщение Васи)
Коля: /tishe (ответ на сообщение Васи)

Бот: 🔇 Вася не может отправлять медиа в течение 24 часов!
     Голосов набрано: 3/3
```

## Запуск в фоне (опционально)

### Использование screen

```bash
screen -S telegram-bot
python bot.py
# Нажмите Ctrl+A, затем D для выхода из screen
# Вернуться: screen -r telegram-bot
```

### Использование systemd (Linux)

Создайте файл `/etc/systemd/system/telegram-bot.service`:

```ini
[Unit]
Description=Telegram Mute Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/antipopog
Environment="PATH=/usr/bin:/usr/local/bin"
ExecStart=/usr/bin/python3 /path/to/antipopog/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем:

```bash
sudo systemctl daemon-reload
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
sudo systemctl status telegram-bot
```

## Настройка параметров

В файле `bot.py` можно изменить параметры:

```python
TISHE_VOTES_REQUIRED = 3  # Количество голосов для запрета медиа
ZAEBAL_VOTES_REQUIRED = 5  # Количество голосов для полного мьюта
RESTRICTION_DURATION = timedelta(hours=24)  # Длительность ограничения
```

## Технические детали

- **Язык:** Python 3.8+
- **Библиотека:** python-telegram-bot 20.7
- **Хранение данных:** В памяти (при перезапуске бота данные о голосах сбрасываются, но активные ограничения в Telegram остаются)

## Безопасность

- Нельзя голосовать за самого себя
- Один пользователь может проголосовать только один раз за конкретное сообщение
- Голоса привязаны к конкретному сообщению
- Ограничения автоматически снимаются через 24 часа

## Решение проблем

### Бот не ограничивает пользователей

Проверьте:
1. Бот добавлен в группу как администратор
2. У бота есть права на блокировку пользователей
3. В логах нет ошибок

### Команды не работают

Убедитесь:
1. Команды отправляются как **ответ** на сообщение
2. Бот запущен и работает
3. Токен в `.env` файле правильный

### Бот не запускается

Проверьте:
1. Установлены все зависимости: `pip install -r requirements.txt`
2. Создан файл `.env` с токеном
3. Токен валидный и не истёк
